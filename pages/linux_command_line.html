Mémento des commandes Linux

Retrouvez les commandes essentielles pour naviguer, manipuler des fichiers et gérer les processus dans un terminal Linux. Utilisez ce mémo comme aide-mémoire pendant vos travaux pratiques.

Conseil

Combinez les options pour gagner du temps. Par exemple ls -lah affiche les fichiers cachés, avec détails et une taille lisible.

Astuces de productivité

Naviguez rapidement dans l'historique avec Ctrl + R et utilisez les flèches haut/bas pour rejouer une commande précédente.

Commandes vues en SISR
Commande Description Exemple d'utilisation
ls Liste les fichiers et dossiers ls -l
cd Change de répertoire courant cd /home/user
pwd Affiche le chemin du dossier actuel pwd
mkdir Crée un nouveau dossier mkdir projets
rm Supprime un fichier rm notes.txt
rm -r Supprime un dossier et son contenu rm -r ancien_projet
cp Copie un fichier ou un dossier cp source.txt sauvegarde.txt
mv Déplace ou renomme un fichier mv rapport.md archives/rapport.md
cat Affiche le contenu d'un fichier cat notes.txt
grep Recherche une chaîne dans un fichier grep "erreur" logs.txt
chmod Modifie les permissions d'un fichier chmod 755 script.sh
sudo Exécute une commande avec les droits administrateur sudo apt update

L'attribut <caption> décrit le tableau, tandis que <th> définit les en-têtes pour chaque colonne afin de clarifier leur rôle.

Raccourcis clavier utiles

  • Ctrl + C : interrompt la commande en cours.
  • Ctrl + L : nettoie le terminal.
  • Tab : autocomplète fichiers et dossiers.
  • Flèche haut/bas : parcourt l'historique des commandes.
