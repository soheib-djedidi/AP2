Feuilles de style en cascade (CSS)

CSS (Cascading Style Sheets) est un langage conçu pour décrire la mise en forme des documents HTML. Il permet de séparer le contenu de la présentation visuelle.

En CSS, vous pouvez définir des règles de style pour des éléments spécifiques ou des groupes d'éléments. Ces règles contrôlent la couleur, la taille, les marges, les polices, et bien d'autres aspects.

Organisation d'une règle CSS

Une règle CSS se compose de trois parties principales :

  • Le sélecteur : l'élément HTML ciblé.
  • La propriété : la caractéristique à modifier.
  • La valeur : la nouvelle valeur appliquée à la propriété.
            
                p {
                  color: #1d4ed8;
                  font-size: 18px;
                }

Dans l'exemple ci-dessus, le sélecteur est p, les propriétés sont color et font-size, et les valeurs respectives sont #1d4ed8 et 18px.

Boîte CSS (CSS Box Model)

Le modèle de boîte définit la manière dont la taille et l'espace d'un élément sont calculés. Chaque élément est considéré comme une boîte comprenant :

  • Le contenu (content)
  • Le remplissage (padding)
  • La bordure (border)
  • La marge (margin)

Comprendre le box model est essentiel pour créer des mises en page précises et responsive.

Bonnes pratiques CSS

  • Utiliser des classes explicites pour décrire la fonction d'un bloc.
  • Regrouper les couleurs et les typographies dans des variables.
  • Limiter la profondeur des sélecteurs pour conserver des styles lisibles.
  • Documenter les zones complexes du code avec des commentaires.
