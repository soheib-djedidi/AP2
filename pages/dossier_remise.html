Dossier de remise – Atelier Professionnel BTS SIO

Cette page rassemble toutes les consignes du document « Atelier Professionnel : Réalisation d’un mini-site web SISR – Dossier à remettre ». Utilisez-la comme guide pour préparer vos livrables et garantir une présentation professionnelle.

Format des documents

Respectez strictement la convention de nommage suivante pour chaque fichier transmis.

Structure de nommage

AP-<classe>-<nom>-<contenu>.<type>

  • <classe> → SIO11 ou SIO12
  • <nom> → votre nom de famille
  • <contenu> → description courte (ex. html-css)
  • <type> → extension du fichier (zip, pdf…)

Formats attendus

  • Documents textuels exportés au format PDF.
  • Mini-site compressé dans une archive ZIP.
  • Captures d'écran insérées et légendées dans le document PDF.

Exemple complet

AP-SIO11-Durand-mini-site.zip
AP-SIO11-Durand-document-technique.pdf

Pensez à vérifier l’orthographe avant l’envoi pour éviter tout rejet administratif.

Contenu du dossier à remettre

Archive du mini-site

Incluez l’intégralité des fichiers HTML, CSS, JavaScript et ressources (images, polices…). Gardez l’arborescence du projet afin que l’enseignant puisse lancer le site immédiatement.

Document explicatif

Décrivez vos choix techniques, les attributs HTML clés et ajoutez un lien vers le dépôt Git si le code est partagé en ligne. Les captures d’écran doivent illustrer :

  • Les corrections effectuées
  • La table des commandes Linux et ses balises
  • Le formulaire de contact du footer
  • Un aperçu de chaque page créée

Astuce : conservez vos captures d’écran en local et intégrez-les uniquement dans le document PDF final. Évitez de les ajouter au dépôt Git pour ne pas bloquer la création d’une demande d’extraction à cause de fichiers binaires.

Chaque capture doit comporter une légende claire pour faciliter l’évaluation lors de l’export PDF.

Explications imposées

Dans le document PDF, n’oubliez pas d’expliquer :

method
Méthode HTTP utilisée lors de l’envoi du formulaire.
action
Adresse vers laquelle les données sont transmises.
required
Obligation de remplir un champ avant l’envoi.
name
Identifiant unique de la donnée reçue côté serveur.

Checklist rapide avant envoi

  1. Vérifier la présence de toutes les pages du mini-site.
  2. Contrôler les liens de navigation et le formulaire de contact.
  3. Exporter le document justificatif en PDF avec légendes.
  4. Compresser le site dans une archive ZIP correctement nommée.
  5. Insérer l’archive et le PDF dans un dossier unique respectant la convention.

Remise du dossier

Le dossier final (ZIP + PDF) doit être déposé sur la plateforme fournie par les enseignants et envoyé par mail via l’ENT. Utilisez une adresse professionnelle et un objet explicite.

Adresse et objet

  • Adresse d’expéditeur de type prenom.nom@domaine.fr.
  • Nom affiché : Prénom Nom.
  • Objet recommandé : Remise dossier AP – Nom Prénom – Classe.

Contenu du mail

Respectez la structure suivante :

Bonjour,

Veuillez trouver ci-joint le dossier « Atelier Professionnel – Mini-site SISR ».
Il contient l'archive ZIP du site ainsi que le document technique au format PDF.

Cordialement,
Nom Prénom – Classe
